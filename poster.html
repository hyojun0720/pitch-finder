02 · 작품 요약

듣기 → 보기 → 고치기 → 만들기

본 작품은 브라우저에서 동작하는 정적 웹 애플리케이션이다. 사용자는 마이크를 켜고 음을 측정한 뒤 멜로디를 녹음한다. 분석 결과는 음표 블록으로 나타나며, 사용자는 높이와 리듬을 수정하고 작곡 결과를 재생·다운로드할 수 있다.

04 · 이론적 배경

소리의 주파수와 음정

소리는 공기의 진동이며, 1초 동안 반복되는 진동 횟수를 주파수(Hz)라고 한다. 사람의 귀는 주파수 차이를 음의 높이 차이로 인식한다. 기준음 A4를 440Hz로 두면 반음 간격은 12등분된 로그 관계로 계산된다.

fn=440×2(n−69)/12n: MIDI 음 번호 · fₙ: 해당 음의 주파수(Hz)

프로그램은 입력 신호의 반복 패턴을 자기상관 방식으로 비교하여 기본 주파수를 추정하고, 가장 가까운 반음의 음 이름으로 변환한다.

n=69+12log2(f/440)주파수 f를 가장 가까운 음계 위치 n으로 변환

07 · 실제 동작 화면

녹음된 멜로디의 타임라인 편집

그림 1. 녹음된 음정이 C·E·F 등의 음 블록으로 표시되고, 작곡 멜로디 재생과 MIDI·WAV 다운로드를 제공하는 실행 화면.

08 · 사용 방법·구동 방식

사용자 조작 흐름

  1. 마이크 사용 권한을 허용한다.
  2. 마이크를 시작하고 한 음 또는 멜로디를 불러본다.
  3. 녹음을 종료하면 전체 시간축에 음과 쉼표가 표시된다.
  4. 음표를 드래그하거나 조성·리듬을 정리한다.
  5. 재생, WAV·MIDI 다운로드, 기록 저장을 사용한다.

음원과 기록은 기본적으로 사용자의 브라우저 안에 저장되어 별도 서버 없이 동작한다.

09 · 작품 설명

음악을 ‘정답 맞히기’에서 ‘발견하기’로

이 작품은 사용자의 목소리를 평가하는 데서 멈추지 않는다. 눈에 보이지 않던 소리를 시간과 높이를 가진 블록으로 바꾸어, 사용자가 자신의 음악적 아이디어를 발견하고 직접 수정하도록 돕는다.
